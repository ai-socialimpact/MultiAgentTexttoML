ImpactLens documentation

ImpactLens lets NGO staff ask questions about their CSV data in plain English. AI writes a small analysis program, the browser runs it, and the answer comes back explained in simple words.

  • 0. High-level designWhat the app does, its components, data flows, dependencies, setup, and known risks and gaps.
  • 1. Design diagrams and the ideaSix diagrams: the idea, the architecture, the retry loop, the strategic and consistency modes, where data lives, and the new role gate and online file loading.
  • 2. How to extend itCode map, step-by-step recipes (add an agent, model, tab, role rule, file source or Firestore field) and a ranked list of improvements.

Updated for the November 26 version of the app: roles, loading files from GitHub, and encrypted CSVs.

Suggested order: read the design, look at the diagrams, then use the extend guide when you start changing code.

Written from reading the source code; the app was not run. Deployment is not covered.
