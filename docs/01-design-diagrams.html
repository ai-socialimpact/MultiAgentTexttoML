ImpactLens: the idea and how it fits together

NGO staff ask questions about their spreadsheets in plain English. AI writes a small analysis program, the browser runs it on their data, and the answer comes back in words the reader's level.

1. The idea in one picture

A person should not need to know code or statistics. Four steps hide that work: understand the question, plan the analysis, write and run the code, then explain the result.

2. Architecture: everything runs in the browser

There is no server of the team's own. The page talks straight to Firebase for sign-in and saved work, and to AI providers for the thinking.

3. The Wizard's safety loop

AI-written code often fails the first time. The Wizard tests it on a few rows, runs it on everything, has another AI judge the output, and tries again with the error message as a hint. It keeps the last three attempts.
